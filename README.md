## 🧩 Profile

안녕하세요. 한성대학교 융합보안학과에 재학 중인 신민석입니다.

저는 **디지털 포렌식, 클라우드 포렌식, 애플리케이션 분석, 리버스 엔지니어링, 랜섬웨어 분석, 보안 자동화** 분야에 관심을 가지고 공부하고 있습니다.

학부 과정 동안 드론 조종기 포렌식, 정보은닉 애플리케이션 암호해제, 클라우드 환경 데이터 획득 및 분석, macOS 통합 로그 분석, 애플리케이션 네트워크 취약점 자동 탐지 등 다양한 연구과제에 참여하였습니다.

이러한 경험을 바탕으로 단순한 이론 학습을 넘어 실제 환경에서 발생하는 보안 문제를 분석하고, 디지털 증거를 수집·검증하며, 포렌식 분석 절차를 자동화하는 역량을 키워가고 있습니다.

---

## 🔬 연구과제 참여 이력

### 🔹 드론 조종기 포렌식 기술 연구 및 분석 방법론 개발

- **연구과제명:** 드론 조종기 포렌식 기술 연구 및 분석 방법론 개발
- **수행기관:** 한국원자력연구원
- **분야:** 디지털 포렌식 / 드론 포렌식

드론 조종기 및 관련 장치에서 발생할 수 있는 디지털 증거를 분석하고, 사용자 행위 흔적과 장치 사용 기록을 식별하기 위한 포렌식 분석 방법론 개발에 참여하였습니다.

---

### 🔹 정보은닉 앱 암호해제 기술 연구개발

- **연구과제명:** 정보은닉 앱 암호해제 기술 연구개발
- **수행기관:** 경찰청
- **분야:** 애플리케이션 포렌식 / 암호화 데이터 분석

정보은닉 애플리케이션 내부에 저장된 암호화 데이터의 구조를 분석하고, 앱 내부 저장 방식과 암·복호화 로직을 파악하여 포렌식 관점에서 데이터 복원 가능성을 검토하는 연구에 참여하였습니다.

---

### 🔹 클라우드 환경의 데이터 획득 및 분석 기술 연구 및 절차 검토

- **연구과제명:** 클라우드 환경의 데이터 획득 및 분석 기술 연구 및 절차 검토
- **수행기관:** 대검찰청
- **분야:** 클라우드 포렌식 / 데이터 획득 및 분석

클라우드 환경에서 데이터를 획득하고 분석하기 위한 기술과 절차를 검토하였으며, 수사 및 포렌식 관점에서 데이터 획득의 신뢰성, 선별 수집 가능성, 분석 절차의 적용 가능성을 연구하였습니다.

---

### 🔹 macOS 환경에서 통합 로그 데이터 분석기법 연구

- **연구과제명:** macOS 환경에서 통합 로그 데이터(ULD) 분석기법 연구
- **수행기관:** 대검찰청
- **분야:** macOS 포렌식 / 통합 로그 분석

macOS 환경에서 생성되는 통합 로그 데이터를 분석하여 사용자 행위, 시스템 동작, 애플리케이션 실행 흔적, 보안 이벤트 등을 식별하기 위한 분석기법 연구에 참여하였습니다.

---

### 🔹 애플리케이션의 네트워크 취약점 자동 탐지 기술 개발에 관한 연구

- **연구과제명:** 어플리케이션의 네트워크 취약점 자동 탐지 기술 개발에 관한 연구
- **수행기관:** 한국연구재단
- **분야:** 애플리케이션 보안 / 네트워크 취약점 분석

애플리케이션의 네트워크 통신 과정에서 발생할 수 있는 보안 취약점을 자동으로 탐지하기 위한 기술 개발 연구에 참여하였습니다. 네트워크 요청 구조, 통신 흐름, 취약 가능 지점 등을 분석하여 자동화된 취약점 탐지 방향을 검토하였습니다.

## 🧩 활동

### 🔹 DEAT · 디지털 포렌식 동아리

**DEAT**는 한성대학교 정보보안 분야 동아리로, **디지털 포렌식, 리버스 엔지니어링, 악성코드 분석, 랜섬웨어 분석, 애플리케이션 분석, 보안 연구**를 중심으로 실습 기반 학습과 연구 활동을 수행하는 동아리입니다.

- **회장** — 2026년 1학기
- **부회장** — 2025년 2학기

동아리 운영진으로 활동하며 보안 분야에 관심 있는 학생들이 실무 중심의 분석 경험을 쌓을 수 있도록 스터디, 실습 과제, 프로젝트 활동, 학술대회 참여 등을 기획하고 지원하고 있습니다.

### 주요 활동 분야

- 애플리케이션 분석
- 악성코드 분석
- 랜섬웨어 분석
- 디지털 포렌식 연구
- 리버스 엔지니어링
- 보안 연구 및 학술대회 참여

### 역할

- 동아리 운영 및 활동 기획
- 보안 실습 과제 구성
- 동아리원 학습 방향 지원
- 디지털 포렌식 및 악성코드 분석 관련 스터디 운영
- 학술대회 및 연구 활동 참여 독려
