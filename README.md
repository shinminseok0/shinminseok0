## [ PROFILE ]

안녕하세요. 한성대학교 융합보안학과에 재학 중인 신민석입니다.

저는 **디지털 포렌식, 클라우드 포렌식, 애플리케이션 분석, 리버스 엔지니어링, 랜섬웨어 분석, 보안 자동화** 분야에 관심을 가지고 공부하고 있습니다.

학부연구원으로 활동하며 드론 조종기 포렌식, 정보은닉 애플리케이션 암호해제, 클라우드 환경 데이터 획득 및 분석, macOS 통합 로그 분석, 애플리케이션 네트워크 취약점 자동 탐지 등 다양한 연구과제에 참여하였습니다.

이러한 경험을 바탕으로 단순한 이론 학습을 넘어 실제 환경에서 발생하는 보안 문제를 분석하고, 디지털 증거를 수집·검증하며, 포렌식 분석 절차를 자동화하는 역량을 키워가고 있습니다.

### 05. 한국정보보호학회장상

<img src="./awards/googledrive.jpeg" align="right" width="180" alt="제9회 부채널정보분석경진대회 한국정보보호학회장상 상장"/>

**대회:** 제9회 부채널정보분석경진대회<br>
**논문명:** Windows/macOS 환경에서의 Google Drive 내부 API 재구성 기반 선택적 메타데이터 수집 및 숨김·삭제된 파일 획득 자동화 도구 구현<br>
**저자:** **신민석**, 최종윤, 김한결, 김대환, 박화비, 박명서<br>
**역할:** 주저자<br>
**수상 내용:** Google Drive 웹 환경에서 발생하는 내부 API 요청 구조를 분석하고 이를 재구성하여, 클라우드 압수수색 과정에서 사건 관련성이 높은 데이터를 선택적으로 수집할 수 있는 자동화 도구를 구현하였습니다. SearchItems 요청과 continuation_token 기반 반복 수집 방식을 활용해 3,216개의 파일 및 폴더 데이터를 수집하였으며, File ID를 기반으로 파일명, 상위 폴더 ID, 생성·수정·열람 시각, 공유 여부, 소유자 정보, 휴지통 여부 및 파일 접근 URL 등의 주요 메타데이터를 획득하였습니다. 또한 숨겨진 작업 공간과 휴지통으로 이동된 파일의 메타데이터 수집, 다중 로그인 환경에서의 계정별 데이터 분리 수집, JSON·TXT·Excel 형식의 결과 저장 기능을 구현한 연구의 기술적 완성도와 클라우드 포렌식 분야의 활용 가능성을 인정받아 한국정보보호학회장상을 수상하였습니다.<br>
